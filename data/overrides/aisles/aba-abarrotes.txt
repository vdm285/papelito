# soups and pasta, as people write them
+ sopa  # "sopa" alone on a list is dry pasta for sopa aguada; QQP "Pasta para Sopa", ENIGH 011912 "Sopas instantáneas"
+ sopa de fideo  # vermicelli for sopa aguada; QQP "Pasta para Sopa" (PRESENTACIÓN "Fideo")
+ sopa de codo  # elbow pasta for sopa; QQP "Pasta para Sopa" (PRESENTACIÓN "Codo")
+ sopa de letras  # alphabet pasta; QQP "Pasta para Sopa" (PRESENTACIÓN "Letras")
+ pasta  # dry pasta in general; QQP "Pasta para Sopa", ENIGH 011150 "pastas italianas" (the head noun is held back because "pasta dental" shares it)
+ coditos  # the everyday diminutive of codo; QQP "Pasta para Sopa" (PRESENTACIÓN "Codo")
+ lasaña  # lasagne sheets; ENIGH 011150 "Spaghetti, pastas italianas y pastas para sopa"
+ macarrones  # macaroni; ENIGH 011150 "pastas italianas"
+ consomé  # bouillon powder (Knorr Suiza); QQP "Concentrado de Pollo", ENIGH 011993 "Concentrados para caldo"
+ consomé de pollo  # as above; without it the item goes to the meat counter through "pollo"
+ cubitos  # bouillon cubes; QQP "Concentrado de Pollo" (PRESENTACIÓN "Cubos")

# baking and spreads

+ grenetina  # unflavoured gelatine; ENIGH 011991 "Levaduras y preparaciones para postres"
+ bicarbonato  # baking soda; ENIGH 011991 "Levaduras y preparaciones para postres"
+ gelatina  # gelatine dessert mix; QQP "Gelatina en Polvo" (the head noun is split between powder and ready cups)
+ hot cakes = 🥞  # pancake mix; QQP "Harina Hot Cakes"; emoji 🥞 (CLDR es-419 "hotcakes")
+ mantequilla de cacahuate  # peanut butter; QQP "Crema de Cacahuate", ENIGH 011842 "Otras mantequillas y cremas"; without it it goes to lácteos through "mantequilla"
+ mantequilla de maní  # peanut butter, as above ("maní" is printed on some jars)
+ miel = 🍯  # honey; QQP "Miel de Abeja", ENIGH 011831 "Miel de abeja"; emoji 🍯 (CLDR "tarro de miel")
+ miel de maple  # pancake syrup; ENIGH 011832 "Otras mieles"
+ stevia  # sweetener; QQP "Sustituto de Azúcar" (brands Svetia, Splenda Stevia)

+ condimentos  # QQP category "Condimentos"
+ laurel  # bay leaves; QQP "Hojas de Laurel"

+ aderezo  # salad dressing; ENIGH 011938 "Otros aderezos y salsas"
